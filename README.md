# English Grammar

Exercices interactifs de grammaire anglaise (5 unités) pour les cours d'anglais de l'IUT Toulouse III Paul Sabatier, disponibles en site web et en application de bureau.

- **Web** : ouvrir `index.html` (une page par unité, un fichier JS par exercice)
- **Bureau** : application Electron, `npm install` puis `npm start`
- **Release** : un tag `v*` déclenche le workflow GitHub Actions qui construit l'installateur Windows et le publie dans les Releases

Auteurs : Samuel DUHEM, Chady BOUZIDA
